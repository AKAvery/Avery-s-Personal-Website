The competition

Longhorn Neurotech’s Fall Competition asks teams to control a robot using biosignals. Our entry was gesture-controlled: read the user’s muscle and brain activity, classify the intended gesture, and drive the robot from it in real time. We took first place.

Networking layer

I owned the Python-to-ESP32 WiFi networking layer, the piece connecting the laptop running inference to the robot actually moving.

Discovery uses UDP broadcast, so the laptop finds the robot on whatever network the venue gives you rather than depending on a hardcoded address. Once found, commands stream over a persistent TCP channel, which keeps ordering and delivery guarantees for the control stream itself while leaving discovery connectionless.

Command protocol

A demo is an adversarial environment: crowded WiFi, one attempt, judges watching. I designed the command protocol with validation and acknowledgement retries, then tuned the reconnect logic specifically against dropped inputs. By the live demo it did not drop a single command.

Almost all of that tuning came from breaking it on purpose beforehand: pulling power, saturating the channel, and watching what the naive version did.

Classifiers

Alongside the networking layer I contributed to the classifiers it carried: EMG hand-gesture and EEG motor-imagery models built from covariance features with logistic regression. I then integrated the trained models into the real-time inference pipeline sitting behind the network layer, so the path from electrode to motor was one continuous system rather than two projects meeting at a file boundary.
